# Mergit v0.7.3 Visual Target

## Product and Goal

- Product: Mergit desktop Git client.
- Primary user: developers using multiple GitHub accounts through system Git.
- Core actions: switch the current repository's GitHub HTTPS account and retry a failed remote operation with diagnostics.
- Primary CTA: `계정 전환` in Settings; `GitHub 복구 시도` is the single primary action inside a recoverable error toast.

## Expanded Design Brief

- Preserve the existing dark, compact, keyboard-friendly Mergit surface.
- Add one necessary `GitHub 계정` section to Settings without creating nested cards or a second navigation layer.
- Keep repository, remote, transport, and selected account as the only visible account metadata. Defer command output to toast details.
- Reuse the existing modal, toast, button, select, pending, focus, and i18n patterns.
- Required states: repository closed, loading, ready, unsupported transport, missing upstream, missing GCM, no saved account, switching, success, failure, recovery running, long account/URL values.

## Benchmark Direction

- Primary reference: Linear.
- Reference signal: restrained dark developer-tool density, sharp alignment, real operational labels, and one clear action per area.
- Do not copy Linear assets, layout, or branding.
- Reject generic SaaS cards, gradients, decorative badges, extra shadows, and marketing copy.

## Composition

- Desktop 1280x800: keep the current `max-w-96` Settings modal and vertical rhythm; place GitHub account controls before Updates.
- Minimum app size 800x600: modal remains scrollable, labels and controls remain reachable, and the toast action row wraps.
- Narrow renderer 390x844: no horizontal overflow; account names and URLs truncate or safely wrap.
- Settings shows one compact metadata list, one labeled select, one full-width primary switch button, and concise state text.
- Recoverable toast shows one primary recovery button and tertiary `상세 보기` / `로그 복사` actions.

## System

- Existing semantic conventions: zinc-900 app background, zinc-800 surfaces, zinc-600/700 borders and controls, zinc-200/300 primary text, zinc-400/500 secondary text, emerald-600/700 primary interaction and success, red-700 error.
- Background policy: preserve the existing near-black application background and zinc modal surface; no new background variation.
- Typography: existing 12px secondary labels and 14px controls/body, regular and semibold only.
- Spacing: existing 4/8/12/16px rhythm.
- Radius: existing `rounded` controls and `rounded-lg` overlays only.
- Shadows: keep the existing toast/modal elevation; add none to account rows or controls.
- Borders: input affordance and existing modal/toast separation only; no account card border.
- Accent: emerald appears only on the active account action and recovery CTA; red remains error-only.
- Motion: existing spinner only, with reduced-motion behavior preserved.
- Long values: truncate account/remote summary with a title; command logs use `whitespace-pre-wrap` and safe word breaking.

## Copy

- Use concrete labels: `GitHub 계정`, `현재 계정`, `원격`, `계정 전환`, `GitHub 복구 시도`.
- One sentence per unsupported or error state.
- Do not repeat visible repository or remote information in helper copy.

## Verification

- Pass 1: verify hierarchy, modal density, toast action priority, and all functional states.
- Pass 2: verify spacing, wrapping, focus, disabled/loading states, contrast, and no-slop checks.
- Capture desktop, minimum-size, and narrow-renderer screenshots.
- Run tests, coverage, typecheck, lint, production build, Lighthouse, quality gate, and Windows packaging.
