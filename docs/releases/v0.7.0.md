# Mergit v0.7.0

## 변경 사항

- `-n`, `--all`처럼 Git 옵션과 닮은 파일명도 지정한 파일만 안전하게 스테이징합니다.
- 최초 커밋 전에도 working tree를 보존하면서 파일을 언스테이징할 수 있습니다.
- 부분 스테이징 파일의 변경 취소는 스테이지된 변경을 유지하고 unstaged 변경만 되돌립니다.
- linked worktree의 분리된 Git metadata를 감시해 외부 commit과 브랜치 변경을 자동 반영합니다.
- 다운로드한 업데이트 상태를 재확인 후에도 유지하고, 업데이트 설치 종료가 일반 종료 확인에 막히지 않게 했습니다.
- Git 변경 작업의 중복 실행을 차단하고 작업 상태 안내를 일관되게 표시합니다.
- 모달의 키보드 포커스, Escape 동작, ARIA 정보와 충돌 해결 draft 폐기 확인을 보강했습니다.
- ConflictEditor와 CodeMirror를 필요할 때만 불러오도록 초기 renderer 번들을 분리했습니다.
- Electron, electron-builder, Vite와 전이 의존성을 호환 가능한 패치 버전으로 갱신했습니다.

## 실행 전 확인

- PC에 Git이 설치되어 있어야 합니다 (`git --version`).
- 코드 서명이 없는 Windows 빌드이므로 SmartScreen 경고가 표시되면 **추가 정보 → 실행**을 선택합니다.
