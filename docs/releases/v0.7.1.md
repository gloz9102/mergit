# Mergit v0.7.1

## 변경 사항

- 바이너리·비 UTF-8·modify/delete 충돌 파일을 텍스트로 덮어쓰지 않고 Ours/Theirs 전체 버전으로 안전하게 해결합니다.
- 충돌 marker 판별을 엄격하게 바꿔 일반 문서의 `=======` 줄을 충돌로 오인하지 않습니다.
- 커밋 추가 로딩과 검색 이동의 경쟁 조건 및 무한 반복 가능성을 제거했습니다.
- 스태시 상세 조회가 실패할 때 같은 요청을 반복하는 문제를 해결했습니다.
- 원격 브랜치와 같은 이름의 로컬 브랜치가 다른 upstream을 가리키면 잘못된 체크아웃을 차단합니다.
- 전체 브랜치 이력에서 stash 내부 커밋을 제외하고 한글 브랜치 검색을 지원합니다.
- 파일 경로와 IPC 인자 검증을 강화하고 Git metadata 우회 접근을 차단했습니다.
- Node.js 22.12 기준, Windows CI, lint와 coverage 검증을 추가했습니다.

## 실행 전 확인

- PC에 Git이 설치되어 있어야 합니다 (`git --version`).
- 코드 서명이 없는 Windows 빌드이므로 SmartScreen 경고가 표시되면 **추가 정보 → 실행**을 선택합니다.
