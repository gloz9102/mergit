# Mergit v0.7.2

## 변경 사항

- Mergit에서 실행한 Git이 시스템의 `PATH`, 사용자 프로필, SSH 에이전트와 Git 인증 환경을 정상적으로 상속하도록 수정했습니다.
- 터미널에서는 원격 작업이 성공하지만 Mergit에서만 실패하던 인증 환경 차이를 해결했습니다.
- 오류 토스트에 `로그 복사` 기능을 추가했습니다.
- 로그 복사 후 Mergit GitHub 버그 이슈 작성 화면을 바로 열 수 있습니다.

## 실행 전 확인

- PC에 Git이 설치되어 있어야 합니다 (`git --version`).
- 코드 서명이 없는 Windows 빌드이므로 SmartScreen 경고가 표시되면 **추가 정보 → 실행**을 선택합니다.
