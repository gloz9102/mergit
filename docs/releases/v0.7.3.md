# Mergit v0.7.3

## 변경 사항

- GitHub 인증 또는 원격 오류 토스트에 `GitHub 복구 시도` 동작을 추가했습니다.
- 열린 저장소에서 현재 경로, 저장소 루트, 브랜치, upstream을 확인한 뒤 `git pull`을 다시 실행하고 명령별 결과를 상세 로그로 제공합니다.
- 설정에서 Git Credential Manager에 저장된 GitHub 계정을 확인하고 현재 저장소의 HTTPS upstream 계정을 전환할 수 있습니다.
- 계정 전환 시 fetch URL과 단일 push URL을 함께 변경하며 실패하면 기존 URL로 복구합니다.
- SSH, GitHub 이외 원격, upstream 없음, GCM 없음, 다중 URL, credential 포함 URL은 이유를 표시하고 변경하지 않습니다.

## 실행 전 확인

- PC에 Git이 설치되어 있어야 합니다 (`git --version`).
- GitHub HTTPS 계정 전환은 Git Credential Manager에 저장된 기존 계정을 사용합니다.
- 코드 서명이 없는 Windows 빌드이므로 SmartScreen 경고가 표시되면 **추가 정보 → 실행**을 선택합니다.
